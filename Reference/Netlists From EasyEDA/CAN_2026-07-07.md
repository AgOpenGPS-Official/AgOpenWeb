> Wiring list for the **CAN** sheet (3 identical FDCAN channels), keyed to the actual EasyEDA
> designators from `CAN-copy_2026-07-07.net`. Sheet exported **unwired** (component list only) — this
> file is the to-wire target. Transceiver = TCAN1042**V**DRQ1 ×3. Cross-sheet rails: `5V_MAIN`
> (always-on), `+3V3`, `GND`. Bus H/L are cross-sheet labels to the combined connector on Page 7.

## Fix / confirm

1. ✅ **L5–L7 = ACT45B-510-2P-TL003 (C76584)** 4-pad footprint placed. **Winding pairing confirmed
   from datasheet: pins 1–4 = one line, pins 2–3 = the other** (not 1-2/3-4). So CANH runs pin1→pin4,
   CANL runs pin2→pin3. (Earlier C167730 was a 2-terminal inductor — correctly discarded.)
2. ✅ **R20 collision resolved** — split-term block renumbered to **R52–R57** (R52/R53 = CAN1,
   R54/R55 = CAN2, R56/R57 = CAN3). No longer clashes with MCU R20.
3. ✅ **VIO bypass added** — C69/C70/C71 (100 nF) on VIO (pin 5) → GND, one per transceiver.
4. **Split-term + CMC populate at bus-ends only** — R20–R25 + C26–C28 (and CMCs) are designed-in but
   DNP on mid-bus nodes; populate the 120 Ω split only where a bus physically terminates.
5. **STB → GND** on all three (U8.8, U9.8, U10.8) = always-on normal mode. Confirmed no GPIO standby.
