# MCU sheet — netlist (as-built + to-wire, real designators)

> Wiring list for the **MCU** schematic sheet, keyed to the actual EasyEDA designators from
> `MCU-copy_2026-07-06.net`. STM32G473RCT6 (U7, LQFP64) + 8 MHz HSE (X1) + support networks.
> Follows planning doc `HARDWARE_AIO_NETLIST.md` Page 3 (§3.1–3.7). One file per sheet.
> Cross-sheet rails: `+3V3` (from Power U3), `GND`. Cross-sheet signals to Power (`PI_PWR_EN`,
> `PI_FLT`, `VIN_SENSE`), CPU (`CM_USB2_P/N`), CAN (Page 4), Serial (Page 5), HMI (Page 7).
>
> **STM32 pin numbers** per §3.7, cross-checked by anchoring the pins I'm certain of on the G4
> LQFP64 (USB PA11/PA12 = 45/46, SWD PA13/PA14 = 49/50, VDD = 16/32/48/64) — that fixes the rest.

## Nets — core power & decoupling

| Net | Nodes |
|---|---|
| `+3V3` (digital) | U7.1 (VBAT), U7.16, U7.32, U7.48, U7.64 (VDD), L4.1 (ferrite **in**), C23.1, C36.1, C37.1, C38.1, C39.1, C40.1, R46.2, H2.1 |
| `+3V3A` (analog) | L4.2 (ferrite **out**), U7.29 (VDDA), U7.28 (VREF+), C42.1, C57.1, C43.1, C58.1 |

> L4 ferrite bridges the rails: +3V3 (L4.1) → +3V3A (L4.2). VDDA + VREF+ both sit on +3V3A
> (ratiometric). C42/C57/C43/C58 are the analog decoupling on +3V3A — **move C42/C57 off +3V3**,
> and the old separate `VREF+` net folds into +3V3A (add U7.28 there, drop the VREF+ label).

## Nets — reset & BOOT0

| Net | Nodes |
|---|---|
| `NRST` | U7.7 (PG10-NRST), C41.1, R46.1 (10 k pull-up → +3V3), H2.5 |

> **No BOOT0 hardware** — BOOT0 is the shared PB8 pin (pin 61 = FDCAN1_RX); handled by option
> bits (`nSWBOOT0=0, nBOOT0=1`) so PB8 is free for CAN. NRST has an internal pull-up; R46 + C41 add
> external pull-up + filter.
