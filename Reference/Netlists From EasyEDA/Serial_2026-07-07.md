# Serial sheet — netlist (to-wire, real designators)

> Wiring list for the **SERIAL / off-board comms** sheet, keyed to the actual EasyEDA designators
> from `Serial-copy_2026-07-07.net`. Sheet exported **unwired** (component list only) — this file is
> the to-wire target. Two links: isolated motor **RS-485** (U11 CA-IS3092W) + non-isolated dual
> **RS-232** (U12 SP3232EEN, NMEA-out + external port). Cross-sheet rails: `+3V3`, `GND`.
>
> **Pinouts verified against datasheets:** CA-IS3092**W** = Chipanalog CA-IS3092/3098 v1.10 (SOIC-16,
> "W" column, integrated iso DC-DC); SP3232EEN = MaxLinear SP3222E/3232E (standard MAX3232 pinout).

| RefDes | Value | Function | Planning |
|---|---|---|---|
| U11 | CA-IS3092W | isolated half-duplex RS-485 + integrated iso DC-DC | U10 |
| U12 | SP3232EEN-L | dual RS-232 transceiver (NMEA-out ch1 + ext ch2) | U11 |
| C44–C47 | 100 nF | SP3232 charge-pump caps | C_SP1–4 |
| C64, C65, C66 | 100 nF | U11 VCC / U11 VISO / U12 VCC bypass | — |

|---|---|

## Nets — RS-485 (U11), isolated field side (separate ground)

| Net | Nodes |
|---|---|
| `VISO_485` | U11.16 (VISO), C65.1, C68.1 |
| `GND_485` | U11.9, U11.15 (GNDB), U11.10 (SEL → GNDB), C65.2, C68.2 — **isolated, do NOT tie to board GND** |
| `RS485_A` | U11.12 (A), R26.1, D8.1 → connector pin 21 |
| `RS485_B` | U11.13 (B), R26.2, D8.2 → connector pin 22 |

> **SEL → GNDB is mandatory:** logic VCC = 3.3 V, so per datasheet SEL must tie GNDB (or float) to set
> VISO = 3.3 V. R26 (120 Ω) terminates across A/B — populate only if this node is a bus end.
> D8 (SMAJ12CA) placed differential across A/B (see fix #4).

## Fix / confirm

1. ✅ **U11 decoupling added** — VCC (pin 1): C64 (0.1 µF) ∥ C67 (10 µF) → GND; VISO (pin 16): C65 (0.1 µF) ∥ C68 (10 µF) → GND_485.
2. ✅ **U12 VCC bypass added** — C66 (0.1 µF) pin 16 → GND. C44–C47 remain the 4 SP3232 pump caps.
3. **LPUART1 not on MCU sheet** — ext-232 TTL nets `LPUART1_TX`/`RX` need U7 PC1 (pin 9) / PC0 (pin 8); add when MCU sheet is revised. PC0/PC1 confirmed free on the MCU export.
4. ✅ **TVS complete** — D8 differential across RS-485 A/B; D9–D12 one per RS-232 field line → GND (NMEA TX/RX + ext TX/RX). All exposed off-board lines clamped.
5. **SEL → GNDB** — mandatory (VCC=3.3 V path); wire U11.10 to GND_485.
6. **Isolation** — keep `GND_485` a separate copper island; the only bridge to the remote is the A/B pair (+ optional cable ground at the connector).
