# GPS slot — netlist (to-label, real designators)

> Wiring guide for the **GPS module slot**, keyed to `GPS-copy_2026-07-07.net`. Two module symbols
> are placed — **P2** (ArduSimple simpleRTK2B, single-F9P) and **U16** (UM982EB, one-module
> dual-antenna heading + INS). The slot is **populate-ONE-option**: stuff P2 *or* U16 and **DNP the
> other** — both wire to the same shared nets, so two populated TX pins would fight on the bus.
> Module symbols export with vendor pin *labels* (no pin numbers), so this sheet is wired by
> **labeling each module pin with our net** — confirm exact silk text on each symbol as you go.
> Cross-sheet: UART4/UART5 (MCU, already labeled on U7), `GPS_PPS` (needs PA15 — fix #2), rails.

## Net ↔ module-pin map  (as-wired — P2 on UART4, U16 on UART5, independent)

The two modules were wired to **separate UARTs** (not the shared populate-one scheme) — P2 = GPS on
UART4, U16 = GPS on UART5. Populate either or both (no bus conflict; different UARTs).

| Our net (= STM label) | STM pin | Module pin (verified in FULL export) |

| `UART5_RX` | U7.55 PD2 (rx) | U16-15 (UM982 **TX** — confirm) |

> **TX/RX crossover** — module TX must land on the MCU's `*_RX` net (module transmits into the STM
