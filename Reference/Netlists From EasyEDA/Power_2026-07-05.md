## Notes / confirm

- **J1** is the ATS-26 (`ATS13-26PA-BM01`); only pins 1 (VIN) and 2 (GND) are used on this sheet.
  Full 26-pin pinout in `HARDWARE_AIO_NETLIST.md` §7.6.
- **C29 = C_dVdt, C30 = C_S1** (both 10 nF 0402) — swap if you placed them the other way.
- **Extras assigned:** C15 → 3rd bulk on `+3V3_NVMe`; C62 → `+3V3` decoupling; C63 → `5V_MAIN`
  decoupling. Confirm that matches intent, or move/delete so the BOM reconciles.
- **D4** = over-voltage clamp: anode on `VIN_SENSE`, cathode on `+3V3`.
- Fuse is external (in-line blade holder in the harness); no board F1.
- **No PWRGD** — the TPS54560 has no power-good pin (pin 8 = SW), so the old `PG1` net is deleted and
  **R41 is now a spare** (delete or DNP). The STM already watches the input via `VIN_SENSE`; if you
  want direct 5V-rail sag detection later, add a `5V_MAIN`→ADC divider on a spare STM pin (optional).
