# CPU sheet — netlist (as-built + to-wire, real designators)

> Wiring list for the **CPU** schematic sheet, keyed to the actual EasyEDA designators from
> `CPU-copy_2026-07-06.net`. CM4 (U19) + M.2 M-key NVMe (U5) + Gigabit RJ45 magjack (L1).
> **USB provisioning port + mux deleted** (provision on the CM4 IO board), but the CM4's single
> native USB 2.0 still forms the **CM4↔STM32 data link** and now wires **directly** to the STM32
> (no mux, since the provisioning port that shared it is gone — resolves the §2.4 "one-USB trap").
> One file per sheet. Cross-sheet rails come from the Power sheet (`Power_2026-07-05.md`):
> `5V_CM`, `+3V3_NVME`, `+3V3`, `GND`.
>
> **Pinouts verified against datasheets:** M.2 Key M = congatec AN43 (PCIe M.2 spec 3.0 v1.2);
> CM4 = official CM4 pinout; PCIe coupling = CM4 datasheet (TX + clock coupling are
> **on-module**, none on carrier).

## Nets — USB 2.0 (CM4 ↔ STM32 data link, direct)

| Net | Nodes |
|---|---|
| `CM_USB2_P` | U19.105 (USB_P / D+) → STM32 PA12 (USB_DP), MCU sheet |
| `CM_USB2_N` | U19.103 (USB_N / D−) → STM32 PA11 (USB_DM), MCU sheet |
| `USB_OTG_ID` | U19.101 → NC (CM4 = host; device/rpiboot mode only used on the CM4 IO board) |

> **Cross-sheet connection = identical label.** `CM_USB2_P` / `CM_USB2_N` are the **canonical
> global-label names**; the MCU sheet MUST place these exact strings on STM32 PA12 / PA11 for the
> nets to join — the "→ STM32 PA12" note here is documentation, not the connection.
> ⚠ **Doc fix:** `HARDWARE_AIO_NETLIST.md` Page 3 calls this pair `USB_CM_D±` — rename to
> `CM_USB2_P/N` so both sheets match.
>
> **Mux (U6) + provisioning ESD (D3/D_PROV) + micro-USB (J_PROV) deleted.** The CM4's one native
> USB 2.0 now goes straight to the STM32 (CM = host ↔ STM = USB-FS device). Internal board trace,
> same ground → no ESD needed. STM-side 0R series options `R_USBP`/`R_USBM` live on the MCU sheet.
> `nRPIBOOT` no longer switches a mux — leave it as a run/recovery strap (pull-up), provisioning
> is done off-board.

## Nets — serial console (CM4 UART0 → H1 header)

| Net | Nodes |
|---|---|
| `CON_TXD` | U19.55 (GPIO14 / TXD0) → H1.2 — CM4 transmit → cable RXD |
| `CON_RXD` | U19.51 (GPIO15 / RXD0) → H1.3 — CM4 receive ← cable TXD |
| `GND` | H1.1 (CM4 pin 53 is a GND right beside 51/55) |

> 3.3 V TTL, not RS-232 — plug a USB-TTL cable (FTDI/CP2102). Header order chosen GND / TXD / RXD
> on pins 1/2/3. Reserve GPIO14/15 for the console → run the CM4↔STM32 link on a different UART
> or SPI (MCU sheet). Optional 100–220 Ω series Rs on TXD/RXD if you want abuse protection.

## Nets — Gigabit Ethernet (U19 CM4 PHY ↔ L1 magjack)

| Net | CM4 (U19) | RJ45 (L1) |
|---|---|---|
| `ETH0_P` / `ETH0_N` | U19.12 / U19.10 (Pair0) | L1.2 / L1.3 (MDI0±) |
| `ETH1_P` / `ETH1_N` | U19.4 / U19.6 (Pair1) | L1.4 / L1.7 (MDI1±) |
| `ETH2_P` / `ETH2_N` | U19.11 / U19.9 (Pair2) | L1.5 / L1.6 (MDI2±) |
| `ETH3_P` / `ETH3_N` | U19.3 / U19.5 (Pair3) | L1.8 / L1.9 (MDI3±) |
| `ETH_LED_GRN` | U19.17 (nLED2) → R13.1 ; R13.2 → L1.12 (GRN cathode) | L1.11 (GRN anode) → +3V3 |
| `ETH_LED_YEL` | U19.19 (nLED1) → R14.1 ; R14.2 → L1.13 (YEL cathode) | L1.14 (YEL anode) → +3V3 |
| `ETH_CT_PHY` | — | L1.**P1** (PHY-side CT common) → C22 → GND |
| `GND` | — | L1.**P10** (internal Bob-Smith return) + shield tabs → GND (no separate chassis net) |

> **Bob Smith is internal to the HR911130C:** cable-side center taps → internal 4× 75 Ω →
> internal 1000 pF → **P10**. So **no external R9–R12 and no external Bob-Smith cap.** We only
> add C22 as the **P1** PHY-side CT bypass to GND. L1 pins mapped: MDI0=2/3, MDI1=4/7, MDI2=5/6,
> MDI3=8/9, P1=CT common, P10=Bob-Smith return, GRN LED=11(A)/12(K), YEL LED=14(A)/13(K),
> shield tabs → GND. **Magjack fully mapped.** Gigabit auto-MDIX means pair *order* to the CM4
> isn't critical, but keep each pair together and P→+, N→−.

## Fix / confirm

1. ✅ **`+3V3_NVME` U5.18 added** (verified in wired export).
1b. ⚠️ **U5 (M.2) GND pins unconnected** — connect **U5.1, 3, 9, 15, 21, 27, 33, 39, 45, 51, 57, 71, 73, 75 → GND**. None are in the GND net yet.
2. **CLKREQ# pull-up = R15** (10k 0402): R15.1 → `PCIE_CLKREQ` (U5.52 / U19.102), R15.2 → +3V3.
3. **PCIe = no carrier coupling caps** — CM4 has TX + clock coupling on-module; M.2 SSD has its own TX coupling. All six PCIe lines wire straight through. Do **not** add series caps.
4. **U19 label** — footprint says CM4101000, part is CM4102000; DF40 is identical, just correct the value field.
5. **LEDs** — using the HR911130C **integrated** green/yellow LEDs, driven by CM4 nLED1/nLED2 through R13/R14. **Delete discrete LED1/LED2** from the schematic + BOM (KT-0603R ×2 removed).
6. **USB = direct CM4↔STM32 link** — delete U6 (mux) + D3 (D_PROV ESD) + J_PROV (micro-USB) from schematic + BOM, but **keep the CM4 USB → STM32 connection**: U19.105→STM32 PA12, U19.103→STM32 PA11 (MCU sheet). Only the *shared provisioning port* is gone, not the data link.
7. **Serial console = H1** (1×3 2.54 mm): H1.2 → U19.55 (GPIO14/TXD0), H1.3 → U19.51 (GPIO15/RXD0), H1.1 → GND. 3.3 V TTL; reserve GPIO14/15 for console.
8. **Ethernet termination is internal to the jack** — HR911130C integrates the cable-side Bob Smith (4× 75 Ω + 1000 pF → P10). **Delete external R9–R12** (75 Ω) and don't add an external Bob-Smith cap. Wire **P10 → GND** and **P1 (PHY-side CT common) → C22 → GND** (single ground — no separate chassis net; shield tabs also → GND). Confirm P1's treatment against the CM4IO / Pi 4 reference (bypass-to-GND is the safe default; some designs tie the CT differently).
