# HMI sheet — netlist (to-wire, real designators)

> Wiring list for the **HMI / panel** sheet, keyed to the actual EasyEDA designators from
> `HMI-copy_2026-07-07.net`. Sheet exported **unwired** (component list only) — this file is the
> to-wire target. Blocks: OLED status display (I²C), recessed reset button, page-scroll rocker
> (hand-fit, on a header), in-case piezo. Cross-sheet rails: `5V_MAIN`, `+3V3`, `GND`.
>
> **Pinouts:** 2N7002 (SOT-23: 1 = Gate, 2 = Source, 3 = Drain); TS-1187A (4-pin tact, 2 pins per
> terminal); PS1240 piezo (2-pin, non-polar); SH1106 module (4-pin I²C, order per silk — see fix #2).
